Open Scholarly Sources

開放學術來源

A human-readable and machine-readable registry of scholarly journals, proceedings, platforms, repositories, directories, aggregators and preprint sources — with access semantics kept explicit.

可人工閱讀、也可機器讀取的學術來源登錄表；期刊、會議論文集、平台、典藏庫、名錄、聚合器與預印本分開描述，不把不同存取狀態粗暴壓成「OA = 是」。

OA semantics / OA 語義： full 表示該來源登錄的學術內容原則上公開；mixed 表示依期刊、文章、年份或平台元件而異；metadata only 只代表可用於發現與中繼資料。收錄不等於背書，也不能取代逐篇全文與正式版本驗證。
