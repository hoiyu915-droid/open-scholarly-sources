Tier semantics / 分級語義： R1/R2 是正式研究出版路線，F1/F2 是前沿／探索路線，D1 是發現基礎設施，A1 是典藏骨架。 Tier 是「怎麼用」的 routing label，不是聲望排行榜；F1 並不低於 R1。高 noise_risk 代表需要更多過濾，不代表來源差。
OA semantics / OA 語義： full 是可公開取得的範圍，不保證所有年代、版本與授權一致；mixed 必須依期刊、文章或年份驗證。 Subscribe to Open 只承認資料中明列的 open_years。
