Open Scholarly Sources

A human-readable and machine-readable registry of scholarly journals, journal families, repositories, directories, aggregators and preprint sources — with access semantics kept explicit instead of collapsing everything into “OA = yes”.

Canonical JSON Schema GitHub repository
OA semantics: full means the source is intended to expose its registered scholarly content openly; mixed means access varies by title/item/year; metadata only means the source is useful for discovery but is not itself a full-text host. Inclusion is not an endorsement and does not replace article-level verification.
