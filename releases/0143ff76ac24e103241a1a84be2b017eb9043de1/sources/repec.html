Research Papers in Economics (RePEc)

RePEc 經濟學研究論文網路

RePEc volunteer network

Large public-domain bibliographic network for economics, especially working-paper series. RePEc points users to contributing archives rather than serving as the canonical full-text host for every record.

大型經濟學書目與工作論文網路，特別適合發現各機構 working-paper series；全文仍回各原始典藏庫取得。
