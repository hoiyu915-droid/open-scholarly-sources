Mutable latest URLs may briefly return an older release through intermediary caches; compare this release ID with the repository main ref when freshness matters. 可變 latest URL 可能因中介快取短暫回傳舊版；需要最新狀態時請核對 release ID 與 main ref。
Tier semantics / 分級語義： R1/R2 是正式研究出版路線，F1/F2 是前沿／探索路線，D1 是發現基礎設施，A1 是典藏骨架。 Tier 是「怎麼用」的 routing label，不是聲望排行榜；F1 並不低於 R1。高 noise_risk 代表需要更多過濾，不代表來源差。
OA semantics / OA 語義： full 是可公開取得的範圍，不保證所有年代、版本與授權一致；mixed 必須依期刊、文章或年份驗證。 Subscribe to Open 只承認資料中明列的 open_years。
Chatbot registry-brokered search / Chatbot Registry 限定搜尋： GitHub connector 先鎖定 main 對應的 immutable release；再由 active registry source 的安全 canonical_url hostname 推導精確 domain restriction。搜尋 broker 的 snippet、排名與摘要只是 discovery， 不能當 evidence；Chatbot 必須開啟原始 OA record、核對 source identity。metadata_only 不得升級成全文證據， shared publisher host 也不足以證明期刊身分。
